# Chesapeake Bay Dinoflagellate Data
This project explores 2 winter bloom species that occur in the Chesapeake Bay, Heterocapsa triquetra and Prorocentrum minimum. The data spans 6 Chesapeake Bay
Program monitoring stations, including Upper, Middle, and Lower Bay locations, and over 40 years, from 1984 to present. Cell counts, water temperature, and salinity 
data will be compiled and analyzed for EDA, and, eventually, my Master's thesis research on these species' distribution and environmental drivers.
